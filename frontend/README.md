# 人脸签到前端

Vue 3 手机页面采用 C「考勤日历」设计。访客可以直接拍照打卡，注册、登录后可以管理标准照并查看考勤。管理员使用服务端分配的账号访问人员照片库。

## 本地运行

在本目录执行以下命令（Node.js 22.12+ 或 24+）。

```sh
npm ci
npm run dev
```

打开终端输出的地址。开发服务器将同源的 `/api` 请求代理到 `http://127.0.0.1:8080`。后端使用其他地址时，可在本目录的 `.env.local` 设置 `API_PROXY_TARGET` 后重启 Vite。

## 联调与部署

执行 `npm run build` 生成 `dist/`，将其作为同站点静态目录，由 Nginx 把原样的 `/api/v1/…` 路径转发至 Spring Boot。生产和手机联调使用 HTTPS，供浏览器创建打卡请求 UUID、使用安全会话 Cookie。手机现场拍摄依赖系统浏览器的相机支持。账号、照片和考勤数据由后端提供。

验证顺序与 [Week 1 接口文档](../docs/week1/REST-API.md) 一致。先注册、登录、刷新和查看标准照，再验证换照、删除和补录。匿名打卡可在已登录其他账号的手机上执行。相同现场照遇到超时、限流或处理中时，在原结果窗口选择「重试本次打卡」；选择「重新拍摄」会为新照片生成新的编号。
